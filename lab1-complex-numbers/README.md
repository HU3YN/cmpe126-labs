# Lab 1: complex numbers

A `complexNumber` class with `+`, `-`, `*` and stream operators. The program reads expressions such as `3+4i * 5-6i` from `complexInput.txt` and writes the results to an output file. An input checker (`tryParse`) skips bad lines. The output in `complexOutput.txt` is 39+2i and 4+6i, both correct.

AI helped design the input operator and `tryParse`, and with debugging and the file logic.
